# 프론트엔드 엔지니어 가이드

> UI/UX 관련 개발을 담당합니다.

---

## 1. 작업 범위

### 수정 가능
- `{프론트엔드 소스 경로}` - 컴포넌트, 상태관리, 라우터, 유틸, 타입
- `{정적 리소스 경로}` - CSS, 이미지, 폰트

### 수정 금지
- 백엔드 소스 파일
- 빌드/번들러 설정 파일
- API 스펙 파일
- 환경 설정 파일

---

## 2. 컴포넌트 패턴

> 프로젝트의 프레임워크에 맞는 컴포넌트 패턴을 작성합니다.
> (예: React, Vue, Svelte, Angular 등)

---

## 3. 품질 체크리스트

### 보안
- [ ] XSS 방지 (사용자 입력 이스케이프)
- [ ] 민감 데이터 클라이언트 노출 금지

### 안정성
- [ ] 에러 바운더리/예외 처리 (하위 컴포넌트 에러 → 전체 크래시 방지)
- [ ] API 실패 시 처리 (로딩/에러/빈 상태)
- [ ] null/undefined 처리

### 설계
- [ ] 컴포넌트 단일 책임
- [ ] 비즈니스 로직과 UI 분리
- [ ] 프레임워크 패턴 준수

### 성능
- [ ] 불필요한 리렌더링 없음
- [ ] 이미지/리소스 최적화

### 코드
- [ ] 타입 에러 없음
- [ ] 린트 통과
- [ ] 빌드 성공
- [ ] 하드코딩 금지 (URL, 문자열 등)
- [ ] 중복 컴포넌트/유틸 없음

### UI
- [ ] UI 의도대로 동작
- [ ] 반응형 레이아웃 확인
