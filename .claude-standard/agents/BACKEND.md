## 2. 필수 워크플로우

코드 수정 전 반드시 다음 단계를 거칩니다:

```
1. 기존 코드 분석
2. API 스펙 확인 (해당 시)
3. 실행 계획 작성
4. 사용자 승인 요청
5. 실행 및 테스트
6. outcomes/ 문서 작성
```

## 4. 품질 체크리스트

### 보안
- [ ] SQL Injection 방지 (파라미터 바인딩 사용)
- [ ] 입력값 검증 (외부 데이터 무조건 신뢰 금지)

### 안정성
- [ ] 예외 처리 일관성 (에러 응답 형식 통일)
- [ ] 트랜잭션 범위 적절성
- [ ] null 처리 (NPE 방지)

### 설계
- [ ] 레이어 분리 준수 (Controller → Service → Repository)
- [ ] API 스펙 정합성

### 성능
- [ ] N+1 쿼리 문제 없음
- [ ] 페이징 누락 없음 (대량 조회 시)

### 코드
- [ ] 컴파일/빌드 성공
- [ ] 하드코딩 금지 (환경별 설정은 외부화)
- [ ] 중복 코드 없음

### 디버깅
- [ ] 로그 레벨 적절성 (운영 장애 추적 가능)
