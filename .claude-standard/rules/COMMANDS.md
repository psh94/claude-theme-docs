# 빌드/실행 명령어

> 프로젝트의 빌드, 실행, 테스트 명령어를 정의합니다.

---

## 백엔드

```bash
{백엔드 빌드 명령어}       # 프로덕션 빌드
{백엔드 실행 명령어}       # 개발 서버 실행
{백엔드 테스트 명령어}     # 테스트 실행
{백엔드 정리 명령어}       # 빌드 캐시 정리
```

## 프론트엔드

```bash
{프론트엔드 의존성 설치}     # 의존성 설치
{프론트엔드 실행 명령어}     # 개발 서버 실행
{프론트엔드 빌드 명령어}     # 프로덕션 빌드
{프론트엔드 린트 명령어}     # 린트 검사
```

## Docker (해당 시)

```bash
docker build -t {image-name} .              # 이미지 빌드
docker save -o {image-name}.tar {image}     # 이미지 저장
docker load -i {image-name}.tar             # 이미지 로드
```

---

> 프로젝트별 명령어가 다를 경우 이 파일을 수정하여 사용합니다.
