# 마이그레이션 원칙

> 레거시 시스템에서 현대적 아키텍처로 전환 시 따르는 원칙입니다.

---

## 핵심 원칙

### 1. UI/UX 동일성
- ORIGIN(원본 시스템)의 UI/UX를 **100% 동일하게** 재현합니다
- ORIGIN CSS와 이미지는 원본 그대로 사용합니다
- 레이아웃, 간격, 색상, 폰트 등 시각적 요소를 보존합니다

### 2. Git/GitHub 수동 운영
- Git 및 GitHub 관련 작업은 자동화하지 않습니다
- 반드시 사용자 확인 후 수동으로 실행합니다

### 3. 미사용 코드 제외
- ORIGIN에서 사용되지 않는 코드는 마이그레이션 범위에서 제외합니다
- 필요한 기능만 선별하여 이전합니다
