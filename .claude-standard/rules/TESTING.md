---

## 2. 테스트 작성 패턴

### 명명 규칙
- 테스트 이름은 `should + 동사` 형태 권장
- `describe`로 대상 그룹화, `it/test`로 개별 케이스

### AAA 패턴
```
Arrange - 테스트 데이터/환경 준비
Act     - 대상 기능 실행
Assert  - 기대 결과 검증
```

## 3. 검증 기준

### 필수 검증
- [ ] 빌드 성공 (컴파일 에러 없음)
- [ ] 기존 테스트 통과 (회귀 방지)
- [ ] 린트 통과

### 권장 검증
- [ ] 신규 기능에 대한 테스트 추가
- [ ] 커버리지 기준 충족: `{최소 커버리지}%`
- [ ] 엣지 케이스 처리 (null, 빈 값, 경계값)
