# 디자인 테스트/검증 규칙

> 디자인 품질 검증을 위한 테스트 전략을 정의합니다.

---

## 1. 테스트 유형

### 컴포넌트 테스트
- 컴포넌트 렌더링 정상 확인
- Props 변경 시 올바른 출력
- 이벤트 핸들링 동작
- 상태 전환 (hover, focus, disabled 등)

### 비주얼 리그레션 테스트
- 스크린샷 비교로 의도하지 않은 시각적 변경 감지
- 반응형 뷰포트별 캡처 (모바일, 태블릿, 데스크톱)
- 다크 모드 / 라이트 모드 각각 캡처

### 접근성 자동 테스트
- aria 속성 올바름
- 색상 대비 충족
- 키보드 네비게이션 가능
- 시맨틱 HTML 구조

---

## 2. 검증 기준

### 필수 검증
- [ ] 빌드 성공
- [ ] 기존 테스트 통과
- [ ] 린트 통과
- [ ] 접근성 자동 검사 통과

### 권장 검증
- [ ] 비주얼 리그레션 통과
- [ ] 스토리북 빌드 성공
- [ ] 크로스 브라우저 확인
- [ ] 반응형 3단계 확인 (모바일/태블릿/데스크톱)

---

## 3. 수동 검증 체크리스트

- [ ] 키보드만으로 전체 흐름 완수 가능
- [ ] 스크린 리더로 콘텐츠 이해 가능
- [ ] 200% 확대 시 레이아웃 깨지지 않음
- [ ] prefers-reduced-motion 대응 확인
