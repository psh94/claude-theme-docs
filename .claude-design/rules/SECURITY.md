# 보안 규칙 - 민감 데이터 보호

> 민감한 데이터의 노출을 방지하기 위한 규칙입니다.

---

## 1. 접근 금지 파일

```
**/.env
**/.env.*
**/*.p12
**/*.jks
**/*.pem
**/*.key
**/credentials*
**/secrets*
{프로젝트별 환경 설정 파일 패턴}
```

---

## 2. 마스킹 대상 패턴

| 유형 | 예시 |
|------|------|
| API 키/시크릿 | `api-key: sk-****` |
| OAuth 자격증명 | `client-secret=****` |
| 인증 토큰 | `Bearer ****` |
| 폰트 라이선스 키 | `font-license: ****` |
| CDN 토큰 | `cdn-token: ****` |

---

## 3. 코드 작성 시 보안 수칙

- XSS: 사용자 입력값 이스케이프 처리
- 하드코딩 금지: API 키, 라이선스 키를 소스코드에 직접 작성하지 않음
- 외부 CDN 리소스: 무결성 해시(SRI) 사용 권장
- 이미지 업로드: 파일 유형/크기 검증
