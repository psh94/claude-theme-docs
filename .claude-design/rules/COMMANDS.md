# 빌드/실행 명령어

> 프로젝트의 빌드, 실행, 테스트 명령어를 정의합니다.

---

## 프론트엔드

```bash
{의존성 설치 명령어}           # 의존성 설치
{개발 서버 실행 명령어}        # 개발 서버 실행
{프로덕션 빌드 명령어}         # 프로덕션 빌드
{린트 명령어}                  # 린트 검사
```

## 디자인 시스템

```bash
{스토리북 실행 명령어}         # 스토리북 개발 서버
{스토리북 빌드 명령어}         # 스토리북 정적 빌드
{토큰 빌드 명령어}             # 디자인 토큰 빌드/변환
```

## 테스트

```bash
{유닛 테스트 명령어}           # 컴포넌트 단위 테스트
{비주얼 테스트 명령어}         # 비주얼 리그레션 테스트
{접근성 테스트 명령어}         # 접근성 자동 검사
```

---

> 프로젝트별 명령어가 다를 경우 이 파일을 수정하여 사용합니다.
