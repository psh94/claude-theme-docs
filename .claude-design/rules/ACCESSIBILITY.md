# 접근성 규칙 (WCAG 2.1 AA)

> 모든 디자인 작업에서 WCAG 2.1 AA 기준을 준수합니다.

---

## 1. 인지 가능 (Perceivable)

### 텍스트 대안
- 모든 `<img>`에 `alt` 속성 필수
- 장식용 이미지는 `alt=""` + `aria-hidden="true"`
- 아이콘 버튼은 `aria-label` 필수

### 색상 대비
| 대상 | 최소 대비 |
|------|----------|
| 일반 텍스트 (< 18pt) | 4.5:1 |
| 큰 텍스트 (≥ 18pt / 14pt bold) | 3:1 |
| UI 컴포넌트/그래픽 | 3:1 |

### 색상 독립성
- 색상만으로 정보를 전달하지 않음
- 에러: 빨간색 + 아이콘 + 텍스트 메시지 조합

---

## 2. 조작 가능 (Operable)

### 키보드
- 모든 인터랙티브 요소 Tab 접근 가능
- 논리적 Tab 순서 (좌→우, 상→하)
- 포커스 인디케이터 visible (outline 제거 금지)
- 키보드 트랩 없음 (모달 제외)

### 포커스 관리
| 상황 | 포커스 동작 |
|------|-----------|
| 모달 열림 | 모달 내부로 이동, 트랩 |
| 모달 닫힘 | 트리거 요소로 복귀 |
| 동적 콘텐츠 추가 | 새 콘텐츠로 이동 또는 공지 |
| 페이지 전환 | 페이지 상단 또는 주요 콘텐츠 |

### 클릭 영역
- 최소 터치 영역: 44 × 44px (모바일)
- 인접 타겟 간 최소 간격: 8px

---

## 3. 이해 가능 (Understandable)

### 폼
- 모든 입력에 `<label>` 연결
- 필수 필드 표시 (시각 + aria-required)
- 에러 메시지는 해당 입력 근처에 표시
- 자동 완성 속성 (`autocomplete`) 적절히 사용

### 언어
- `<html lang="{언어 코드}">` 필수
- 다국어 콘텐츠는 `lang` 속성으로 구분

---

## 4. 견고함 (Robust)

### 시맨틱 HTML
| 용도 | 올바른 태그 |
|------|-----------|
| 네비게이션 | `<nav>` |
| 주요 콘텐츠 | `<main>` |
| 섹션 제목 | `<h1>`~`<h6>` (순서 건너뛰지 않기) |
| 목록 | `<ul>`, `<ol>`, `<li>` |
| 버튼 | `<button>` (div/span 금지) |
| 링크 | `<a>` (새 페이지 이동 시) |

### ARIA
- 시맨틱 HTML로 충분하면 ARIA 불필요
- 커스텀 컴포넌트에만 ARIA role/속성 추가
- aria-live="polite" - 동적 콘텐츠 알림
- aria-expanded - 펼침/접기 상태

---

## 5. 모션/애니메이션

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
- 자동 재생 동영상/애니메이션 정지 버튼 필수
- 깜빡임 3회/초 미만
