## 3. 주요 디렉토리 구조

```
{프로젝트 루트}/
├── {컴포넌트 경로}/
│   ├── {기본 컴포넌트}/      # Button, Input, Modal 등
│   ├── {레이아웃 컴포넌트}/   # Header, Footer, Sidebar 등
│   └── {페이지 컴포넌트}/     # 페이지 단위 조합
├── {스타일 경로}/
│   ├── {토큰 파일}/           # 디자인 토큰
│   ├── {글로벌 스타일}/       # 리셋, 기본 스타일
│   └── {테마 파일}/           # 라이트/다크 테마
├── {에셋 경로}/
│   ├── {아이콘}/
│   ├── {이미지}/
│   └── {폰트}/
└── {스토리북 경로}/
```
